# Query Builder

The interactive Query Builder reads the live SQLite catalog, auto-selects a sole table, and guides column selection, filters, aggregates, sorting, limits, JOIN, UNION, and materialization.

**Use this query** is the single preview path. It opens the shared query screen where SQL can be edited, copied, executed, parameterized, or turned into a view. **Create View** stores the SQL definition; **CREATE TABLE AS** copies the current rows.

JOIN walks through the first table, second table, JOIN type, one typed column from each side, and optional output columns. Every nested Back/Cancel returns to the Query Builder rather than the main menu.
