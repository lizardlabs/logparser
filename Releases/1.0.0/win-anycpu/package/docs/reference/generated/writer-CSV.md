# CSV writer

Comma-separated values for spreadsheets and data interchange

- **Category:** Delimited
- **Default extension:** .csv
- **Streaming:** yes

## Parameters

| Property | Display name | Type | Required | Default | Description |
| --- | --- | --- | --- | --- | --- |
| `IncludeHeaders` | IncludeHeaders | boolean value | No | `True` | Specifies whether to include column headers in the CSV output. |
| `IgnoreNullFields` | IgnoreNullFields | boolean value | No | `True` | Compatibility option. CSV always preserves every column position; null values are written as empty fields. |
| `Delimiter` | Delimiter | string value | No | `,` | Specifies the delimiter to use in the CSV output (e.g., ',' or ';'). |
| `Quote` | Quote | unknown | No | `"` | Specifies the quote character to use for enclosing fields in the CSV output. |
| `Escape` | Escape | unknown | No | `"` | Specifies the escape character to use for escaping special characters in the CSV output. |
| `IgnoreEmptyResults` | Ignore empty result sets | boolean value | No | `False` | Skip empty result-set sections when the selected format supports it. |
