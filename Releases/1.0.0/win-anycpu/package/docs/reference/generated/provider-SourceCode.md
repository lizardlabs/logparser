# C#, VB.NET, Razor, HTML, JavaScript, TypeScript, and Markdown files parsed into searchable symbols, document structure, comments, diagnostics, and exact source spans: -i=SourceCode

## Description

C#, VB.NET, Razor, HTML, JavaScript, TypeScript, and Markdown files parsed into searchable symbols, document structure, comments, diagnostics, and exact source spans. Command line switch to use this input format is -i=SourceCode.

**Category:** Source code
**Aliases:** `CSharp`, `CS`

This provider exposes searchable symbols and document structure from C#, VB.NET, Razor, HTML, JavaScript, TypeScript, and Markdown files. Results can include declarations, sections, markup, expressions, imports, comments, diagnostics, and exact source spans. Enable `IncludeSourceLines` when a grep-like row for every source line is useful.

## Incremental input and checkpoints

Set `CheckpointFile` to process only records appended since the last successful query. The first run reads the complete source. ULP stages positions in memory and atomically updates the checkpoint only after the query, output writer, and after-query hook succeed; errors and cancellation leave the previous checkpoint unchanged.

Seekable file streams store a byte offset plus a prefix fingerprint. New files are read completely, deleted files are removed after a complete scan, and truncated or replaced files restart from the beginning. If a query stops before a file reaches end-of-stream (for example, an early `LIMIT`), that file is safely replayed on the next run rather than risking skipped records. Compressed/archive and other non-seekable streams currently read normally without advancing a byte checkpoint.

A checkpoint filename without a directory is resolved in the system temporary directory for Microsoft Log Parser compatibility. Prefer an explicit path for services, scheduled tasks, containers, and shared deployments.

Checkpoint state describes input positions, not SQL aggregate state. For example, `COUNT(*)` reports the number of new records in that execution, not the lifetime total.

## Data Provider

Use one or more `.cs`, `.vb`, `.razor`, `.cshtml`, `.html`, `.htm`, `.xhtml`, `.js`, `.mjs`, `.cjs`, `.jsx`, `.ts`, `.tsx`, `.mts`, `.cts`, `.md`, `.markdown`, `.mdown`, `.mkd`, or `.mdx` paths or glob patterns. `Recurse` defaults to `-1`; generated files and common dependency/build directories are excluded unless explicitly enabled or removed from `ExcludedPathSegments`. Use `IncludedLanguages` (`CSharp`, `VisualBasic`, `Razor`, `Html`, `JavaScript`, `TypeScript`, or `Markdown`) to restrict the registered readers. `MaximumFiles`, `MaximumFileSizeBytes`, `MaximumRowsPerFile`, `FileNamePattern`, and `FileContainsText` bound or prefilter work before parsing.

```sql
CREATE VIRTUAL TABLE code_rows USING ParsingModule('.\*',
  '-i:SourceCode -Recurse:-1 -IncludeComments:OFF -IncludeDiagnostics:OFF');
SELECT Kind, FullName, SourcePath, StartLine, EndLine
FROM code_rows WHERE Name LIKE '%Parser%' ORDER BY SourcePath, StartLine;
```

## Coding-agent workflows

Use `Language`, `Kind`, `Name`, `FullName`, `ParentName`, `Namespace`, and exact `StartLine`/`EndLine` values for navigation. C# and VB.NET results include declarations and symbols. Razor, HTML, JavaScript, TypeScript, and Markdown results expose useful document structure without running or rendering the files. Results may include declarations, imports, sections, markup, links, comments, embedded blocks, behavior hints, and recoverable diagnostics. `CalledMethods`, complexity values, and `Has*` fields are search and triage hints rather than compiler or security verdicts.

The bundled Query library provides focused commands for symbols, structured metadata, exact text/context, comments, calls, imports, inheritance, documentation, diagnostics, behavior hints, public APIs, duplicate bodies, inventory, and complexity hotspots. Examples include `ulp -c.code-symbol`, `ulp -c.code-context`, `ulp -c.code-comments`, `ulp -c.code-behavior`, and `ulp -c.code-hotspots`. Override their default `.\*` source with `--from` and pass native parameters such as `--p.name Parser` or `--p.text TODO`.

For exact line search, set `IncludeSourceLines:ON` and `IncludedKinds:SourceLine`, then filter `FullRecord` with `LIKE` or `Rx_Is_Match`. For declaration bodies, leave `IncludeFullRecord` enabled and query structured member rows. Syntax diagnostics are available as `Kind='Diagnostic'`; semantic compilation diagnostics are outside this provider's current scope.
