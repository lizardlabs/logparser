# Active Directory objects and properties with Microsoft Log Parser 2.2-compatible modes: -i=ADS

## Description

Active Directory objects and properties with Microsoft Log Parser 2.2-compatible modes. Command line switch to use this input format is -i=ADS.

**Category:** Directory services
**Aliases:** `ActiveDirectory`, `LDAP`

This provider follows Microsoft Log Parser 2.2's ADS input contract. Leave `ObjClass` empty for Property Mode (one row per directory property), or set it to a class such as `user` for Object Mode (one row per matching object with schema-discovered columns).

## Data Provider

Use the Microsoft ADS source syntax `[[provider:]//[username:password@]server]/path`; separate multiple paths with semicolons. `LDAP://server/CN=Users,DC=example,DC=com` is the usual Active Directory form. The documented compatibility defaults are provider `IIS`, server `localhost`, current Windows credentials, and recursive traversal. Prefer `-Username` plus a secret reference for credentials rather than embedding a password in the path.

```sql
CREATE VIRTUAL TABLE directory_users USING ParsingModule(
  'LDAP://dc01/CN=Users,DC=example,DC=com',
  '-i:ADS -ObjClass:user');
SELECT name, title FROM directory_users WHERE title IS NOT NULL;
```

## Parameters
Parameters for configuring 'Active Directory objects and properties with Microsoft Log Parser 2.2-compatible
modes'. Quote string values that contain spaces. Boolean values accept True/False, ON/OFF, or 1/0. Date-time
values use ISO forms such as 2021-05-16 or 2021-05-16 12:40:23. Numbers are unquoted and arrays use
comma-separated values. Nested setting groups use dotted parameter names.

### Active Directory query

| Parameter | Type and default | Description |

| `-MaximumObjects` | integer number; default 0 | Maximum directory objects returned from each ADS path. 0 keeps the Microsoft-compatible unlimited behavior.  |
