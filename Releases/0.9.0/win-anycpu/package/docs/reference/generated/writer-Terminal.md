# Terminal writer

Formatted terminal table with colors and borders (default)

## Parameters

| Property | Display name | Type | Required | Default | Description |
| --- | --- | --- | --- | --- | --- |
| `EnableColoring` | Enable coloring | boolean value | No | `True` | Enable or disable colored output. |
| `ShowTableBorders` | Show table borders | boolean value | No | `True` | Enable or disable table borders. |
| `TableBorderStyle` | Table border style | object | No | `Rounded` | Set the table border style. |
| `PagingMode` | Paging mode | list of values | No | `Auto` | Page long terminal results automatically, always, or never. While paging, press A to show all remaining content in terminal scrollback. |
| `IgnoreEmptyResults` | Ignore empty result sets | boolean value | No | `False` | Skip empty result-set sections when the selected format supports it. |
