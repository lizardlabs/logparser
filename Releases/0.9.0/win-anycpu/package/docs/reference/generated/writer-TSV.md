# TSV writer

Tab-separated values for lossless plain-text interchange

- **Category:** Delimited
- **Default extension:** .tsv
- **Streaming:** yes

## Parameters

| Property | Display name | Type | Required | Default | Description |
| --- | --- | --- | --- | --- | --- |
| `IncludeHeaders` | IncludeHeaders | boolean value | No | `True` | Specifies whether to include column headers in the TSV output. |
| `IgnoreNullFields` | IgnoreNullFields | boolean value | No | `True` | Specifies whether to ignore null fields in the TSV output. |
| `EscapeSpecialCharacters` | EscapeSpecialCharacters | boolean value | No | `True` | Specifies whether to escape special characters (e.g., tabs, newlines) in the TSV output. |
| `IgnoreEmptyResults` | Ignore empty result sets | boolean value | No | `False` | Skip empty result-set sections when the selected format supports it. |
