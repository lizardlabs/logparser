# Scriban writer

Scriban template rendering and safe multi-file generation

- **Category:** Generation
- **Default extension:** .txt
- **Streaming:** buffers the result
- **Aliases:** `Template`

## Parameters

| Property | Display name | Type | Required | Default | Description |
| --- | --- | --- | --- | --- | --- |
| `InlineTemplate` | Inline template | string value | No | `NULL` | Inline Scriban template text. Use only one of InlineTemplate, TemplateFile, TemplateFiles, or TemplateDirectory. |
| `TemplateFile` | Template file | string value | No | `NULL` | Path to one Scriban template file. |
| `TemplateFiles` | Template files | string value | No | `NULL` | Semicolon-separated Scriban template file paths, rendered in supplied order. |
| `TemplateDirectory` | Template directory | string value | No | `NULL` | Directory containing templates. Each template becomes an output file beneath the selected output root. |
| `SearchPattern` | Search pattern | string value | No | `*.scriban` | Template-directory file pattern. The default is *.scriban. |
| `Recursive` | Recursive directory | boolean value | No | `True` | Search the template directory and its subdirectories. |
| `StrictVariables` | Strict variables | boolean value | No | `True` | Fail when a template references a missing variable or member. |
| `TemplateSeparator` | Template separator | string value | No | `<br>` | Text inserted between multiple template or per-row renders written to stdout or one file. |
| `IgnoreEmptyResults` | Ignore empty result sets | boolean value | No | `False` | Skip empty result-set sections when the selected format supports it. |
