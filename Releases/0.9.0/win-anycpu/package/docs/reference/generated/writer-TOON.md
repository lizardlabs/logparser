# TOON writer

TOON 4.1 token-oriented tabular output for LLM contexts

ULP emits one TOON 4.1 tabular array per SQLite result set (`Table0`, `Table1`, ...). Duplicate SQL column names receive `_2`, `_3`, and so on; dates use ISO 8601 strings, binary values use Base64 strings, and non-finite floating-point values become `null`. TOON works best for uniform tables. See the [TOON 4.1 specification](https://github.com/toon-format/spec/blob/main/SPEC.md).

- **Category:** Structured
- **Default extension:** .toon
- **Streaming:** buffers the result
