# Grok pattern provenance

`patterns/grok/notice.txt` states that some installed patterns were copied from the Logstash `logstash-patterns-core` repository and preserves the Elasticsearch Apache License 2.0 notice. The notice governs the installed `.grokpatterns` files derived from that source; locally authored additions should identify their origin in the same directory or a per-file header.

Source: `https://github.com/logstash-plugins/logstash-patterns-core/tree/master/patterns`

License text: `../licenses/Apache-2.0.txt`

The package inventory treats all shipped `.grokpatterns` files as Apache-2.0 unless a more specific per-file notice is added. This is conservative attribution and does not imply Elasticsearch authorship of separately documented local patterns.
