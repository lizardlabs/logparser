# Guided menu

Use the menu to discover data providers, configure properties, browse the Query library, build SQL, and select an output without memorizing switches.

```powershell
ulp --menu
```

Beginner mode is the default. Use `--advanced-menu` when you need the SQL shell, SQLite connection options, jobs, or multiple outputs. Choose a source, review its virtual-table SQL, then inspect columns before composing a query. The shared query review screen lets you edit, copy, execute, or go back.
