# Batch automation

ULP keeps result data on standard output and sends diagnostics to standard error. Normal mode prints results or a concise error. `--verbose` adds table creation, timing, condition, and post-action decisions. `--stats` emits one compact JSON summary to standard error. `--quiet` suppresses optional diagnostic messages but does not hide query results. `--silent` suppresses results and optional console diagnostics while preserving errors, exit codes, file outputs, and configured logs.

## Exit codes

| Code | Meaning |
| ---: | --- |
| 0 | Query and requested post-action succeeded |
| 1 | Unexpected application failure |
| 2 | Invalid command line or configuration |
| 3 | SQLite, query, or provider execution failure |
| 4 | Required rows, scalar, or SQL condition not met |
| 5 | Output path or writer failure |
| 6 | Post-action failed, timed out, or returned nonzero |

## Result gates

- `--require-rows` requires at least one rendered row.
- `--expect-scalar <value>` compares the first row's first column using an exact invariant string representation.
- `--condition-query <sql> --require-condition` runs a separate scalar query after the main batch. Boolean true, nonzero numbers, and nonempty strings other than `false` are true.
- `--output none` consumes results and collects metrics without writing result data.

```powershell
ulp --query "SELECT COUNT(*) FROM alerts WHERE severity='critical'" `
    --output none --condition-query "SELECT EXISTS(SELECT 1 FROM alerts WHERE severity='critical')" `
    --require-condition --stats
```

## Conditional files

`--no-output-if-empty` writes textual output to a temporary sibling file. ULP publishes it only when at least one row was written. When no rows exist, no target is created and an existing target is left unchanged.

## Post-actions

`--after <executable>` is opt-in and never invokes an implicit command shell. Add arguments with repeated `--after-arg`; use `--after-arg=<value>` when a value begins with `-`. `--after-when` accepts `success`, `rows`, `empty`, `file`, or `condition`. The default timeout is 300 seconds and can be changed with `--after-timeout`.

The child receives `ULP_ROWS`, `ULP_RESULT_SETS`, `ULP_FIRST_VALUE`, `ULP_OUTPUT_FILE`, and `ULP_CONDITION`. A nonzero child exit or timeout makes ULP exit 6.

```powershell
ulp --query "SELECT * FROM alerts WHERE severity='critical'" `
    --output file --format JSON --output-file critical.json --no-output-if-empty `
    --after notify.exe --after-arg critical.json --after-when file
```

ULP does not include a mail sender because credentials, retry rules, and delivery providers belong outside a log parser. Invoke a purpose-built notifier, workflow runner, or script explicitly instead.
