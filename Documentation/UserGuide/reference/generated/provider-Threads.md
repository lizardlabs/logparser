# Point-in-time operating-system thread state, priority, and CPU metrics for selected processes: -i=Threads

## Description

Point-in-time operating-system thread state, priority, and CPU metrics for selected processes. Command line switch to use this input format is -i=Threads.

**Category:** System snapshots
**Aliases:** `ProcessThreads`, `THR`

This is a bounded, point-in-time local-machine snapshot, not a continuous performance monitor. Set `CpuSampleMilliseconds` above zero to include a short CPU-usage sample normalized across the machine's logical processors.

## Data Provider

Use `*`, `.`, `local`, `localhost`, or `system` for every local process. To reduce access and sampling cost before SQLite runs, use a comma/semicolon-separated list of process IDs or executable names (the `.exe` suffix is optional). Missing PIDs and names produce no rows.

```sql
CREATE VIRTUAL TABLE thread_snapshot USING ParsingModule('ulp', '-i:Threads -CpuSampleMilliseconds:250');
SELECT ProcessId, ThreadId, ThreadState, WaitReason, round(CpuPercent, 2) AS CpuPercent
FROM thread_snapshot ORDER BY CpuPercent DESC;
```
