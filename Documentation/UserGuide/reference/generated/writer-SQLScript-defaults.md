Factory defaults, before saved configuration or command-line overrides. Copy the applicable entries into an application `.config` file. Select the format separately. Unset, complex, unavailable, and secret values are comments, not fabricated command values. Dates, paths, and culture can reflect the environment where this reference was generated; copying them fixes those values rather than preserving a moving date range. Unicode escapes preserve embedded quotes safely.
