# Excel workbooks and worksheets without Office or database drivers: -i=Excel

## Description

Excel workbooks and worksheets without Office or database drivers. Command line switch to use this input format is -i=Excel.

**Category:** Structured data
**Aliases:** `XLSX`, `XLS`

## Data Provider

Depending on the provider, the source used with `Excel` can be:
- One or more local paths, optionally containing glob wildcards.
- An HTTP, FTP, or S3 URL when remote input is supported.
- A provider-specific name or value, such as a Windows Event Log channel.

For stream-based providers, comma/semicolon-separated file sources are expanded lazily. Prefix exclusions with `!` (`C:\logs\*;!*.txt`); an exclusion-only list implies `*`, and `!!name` escapes a literal leading exclamation mark. Use `archive.zip|*.log` to stream matching archive entries. Encrypted archives can read a password from an environment variable with `file:///C:/logs.zip?password-env=ULP_ARCHIVE_PASSWORD|*.log`.

## Output Fields

| Field | Type | Description |
| --- | --- | --- |
| `WorkbookFile` | string | Full path of the source workbook. |
| `Worksheet` | string | Worksheet name. |
| `WorksheetIndex` | integer | One-based worksheet position in the workbook. |
| `RowNumber` | integer | One-based source row number in the worksheet. |

Worksheet columns follow these metadata fields and are discovered from the selected header row.
