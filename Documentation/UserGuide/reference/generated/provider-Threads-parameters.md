These paths apply beneath `--input.` on the command line. Inside ParsingModule input options, use `-Path:Value`. Inherited means the option is supplied by shared configuration, not that it needs an extra path prefix. Configuration groups are not result columns.

| Full path | Name | Type | Default | Inherited | Description | Configuration reference |
| --- | --- | --- | --- | --- | --- | --- |
| `ComputerName` | ComputerName | string | "" | Yes | Computer to snapshot. Leave empty or use '.', 'localhost', or the local computer name for this computer. A remote name uses Windows System.Diagnostics access and never falls back to the local computer. | — |
| `CpuSampleMilliseconds` | CpuSampleMilliseconds | Int32 | 200 | Yes | Delay between CPU counter samples. 0 returns CPU totals without calculating CPU percentage; values from 100 to 1000 usually give useful snapshots. | — |
| `IgnoreInaccessible` | IgnoreInaccessible | boolean | True | Yes | Return partial rows when a process exits or denies access. When disabled, the first inaccessible requested field stops the query. | — |
| `IncludeDetails` | IncludeDetails | boolean | True | Yes | Attempt to read fields such as executable path, version, start time, and detailed CPU counters. Some operating-system processes deny access to these fields. | — |
| `MaximumRows` | MaximumRows | Int32 | 0 | Yes | Maximum rows returned by the snapshot. 0 returns every selected row. | — |
