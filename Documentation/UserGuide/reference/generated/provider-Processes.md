# Point-in-time local process metrics including memory, CPU, handles, threads, and executable details: -i=Processes

## Description

Point-in-time local process metrics including memory, CPU, handles, threads, and executable details. Command line switch to use this input format is -i=Processes.

**Category:** System snapshots
**Aliases:** `Process`, `PROC`

This is a bounded, point-in-time local-machine snapshot, not a continuous performance monitor. Set `CpuSampleMilliseconds` above zero to include a short CPU-usage sample normalized across the machine's logical processors.

## Data Provider

Use `*`, `.`, `local`, `localhost`, or `system` for every local process. To reduce access and sampling cost before SQLite runs, use a comma/semicolon-separated list of process IDs or executable names (the `.exe` suffix is optional). Missing PIDs and names produce no rows.

```sql
CREATE VIRTUAL TABLE process_snapshot USING ParsingModule('*', '-i:Processes -CpuSampleMilliseconds:250');
SELECT ProcessId, ProcessName, round(CpuPercent, 2) AS CpuPercent,
       HUMANIZE_BYTES(WorkingSetBytes) AS WorkingSet
FROM process_snapshot ORDER BY WorkingSetBytes DESC LIMIT 20;
```
