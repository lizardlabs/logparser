# Processes — default configuration

[Format overview](provider-Processes.md) · [All parameters](provider-Processes-parameters.md) · [Defaults](provider-Processes-defaults.md) · [User guide](../../inputs-and-outputs.md)

Factory defaults, before saved configuration or command-line overrides. Copy the applicable entries into an application `.config` file. Select the format separately. Unset, complex, unavailable, and secret values are comments, not fabricated command values. Dates, paths, and culture can reflect the environment where this reference was generated; copying them fixes those values rather than preserving a moving date range. Unicode escapes preserve embedded quotes safely.

```text
--input.ComputerName=""
--input.CpuSampleMilliseconds=200
--input.IgnoreInaccessible=True
--input.IncludeDetails=True
--input.MaximumRows=0
```

Defaults are values, not a recommendation to enable every feature. Preserve dependency switches such as `EnableAdvancedRecordConfiguration`; configuring a nested group does not necessarily enable its use.
