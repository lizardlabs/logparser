# AdvancedTextReaderOptions configuration

This is a public settings-group reference, not an instruction to construct application objects. The full path and actual default depend on the selected format and containing group; use its parameters/defaults links.

| Relative parameter | Type | Inherited | Description | Related configuration |
| --- | --- | --- | --- | --- |
| `CodePage` | Int32 | No | Code page for the log files. Default is UTF-8 (65001). | — |
