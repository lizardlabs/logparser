# YAML documents, mappings, and sequences from files or streams: -i=YAML

## Description

YAML documents, mappings, and sequences from files or streams. Command line switch to use this input format is -i=YAML.

**Category:** Structured text
**Aliases:** `YML`

A top-level YAML sequence produces one SQLite row per item. Use `RecordPath` for a nested sequence. Nested mappings are flattened to dot-separated column names by default, while nested sequences are preserved as compact JSON strings.

## Incremental input and checkpoints

Set `CheckpointFile` to process only records appended since the last successful query. The first run reads the complete source. ULP stages positions in memory and atomically updates the checkpoint only after the query, output writer, and after-query hook succeed; errors and cancellation leave the previous checkpoint unchanged.

Seekable file streams store a byte offset plus a prefix fingerprint. New files are read completely, deleted files are removed after a complete scan, and truncated or replaced files restart from the beginning. If a query stops before a file reaches end-of-stream (for example, an early `LIMIT`), that file is safely replayed on the next run rather than risking skipped records. Compressed/archive and other non-seekable streams currently read normally without advancing a byte checkpoint.

A checkpoint filename without a directory is resolved in the system temporary directory. Prefer an explicit path for services, scheduled tasks, containers, and shared deployments.

Checkpoint state describes input positions, not SQL aggregate state. For example, `COUNT(*)` reports the number of new records in that execution, not the lifetime total.

## Data Provider

Depending on the provider, the source used with `YAML` can be:
- One or more local paths, optionally containing glob wildcards.
- An HTTP, FTP, or S3 URL when remote input is supported.
- A provider-specific name or value, such as a Windows Event Log channel.

For stream-based providers, comma/semicolon-separated file sources are expanded lazily. Prefix exclusions with `!` (`C:\logs\*;!*.txt`); an exclusion-only list implies `*`, and `!!name` escapes a literal leading exclamation mark. Use `archive.zip|*.log` to stream matching archive entries. Encrypted archives can read a password from an environment variable with `file:///C:/logs.zip?password-env=ULP_ARCHIVE_PASSWORD|*.log`.

## Parameters
Parameters for configuring 'YAML documents, mappings, and sequences from files or streams'. Quote string
values that contain spaces. Boolean values accept True/False, ON/OFF, or 1/0. Date-time values use ISO forms
such as 2021-05-16 or 2021-05-16 12:40:23. Numbers are unquoted and arrays use comma-separated values. Nested
setting groups use dotted parameter names.
