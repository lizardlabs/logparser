# Markdown writer

Markdown tables suitable for documentation and chat

- **Category:** Document
- **Default extension:** .md
- **Streaming:** buffers the result
- **Aliases:** `MD`

## Parameters

| Property | Display name | Type | Required | Default | Description |
| --- | --- | --- | --- | --- | --- |
| `IncludeHeader` | IncludeHeader | boolean value | No | `True` | Specifies whether to include the header row in the markdown output. |
| `ColumnAlignment` | ColumnAlignment | list of values | No | `Unspecified` | Defines the alignment of table columns in the markdown output. |
| `RenderIndent` | RenderIndent | boolean value | No | `False` | Indicates whether to render the markdown table with indentation. |
| `MaxCellWidth` | MaxCellWidth | integer number | No | `50` | Specifies the maximum width of a cell in the markdown table. |
