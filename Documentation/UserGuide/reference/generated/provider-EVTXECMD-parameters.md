# EVTXECMD — all parameters

These paths apply beneath `--input.` on the command line. Inside ParsingModule input options, use `-Path:Value`. Inherited means the option is supplied by shared configuration, not that it needs an extra path prefix. Configuration groups are not result columns.

| Full path | Name | Type | Default | Inherited | Description | Configuration reference |
| --- | --- | --- | --- | --- | --- | --- |
| `MapsDirectory` | MapsDirectory | string | "EvtxECmd\\Maps" | No | EvtxECmd Maps directory. Stored under the Documents folder by default. Must be updated manually (e.g., via Git). The application does not auto-update maps from the EvtxECmd repository (https://github.com/EricZimmerman/evtx). | — |
| `Recurse` | Recurse | Int32 | 0 | Yes | Maximum recursion depth for subdirectories when reading file streams. 0 disables recursion; -1 enables unlimited recursion. | — |
| `CheckpointCompleteLinesOnly` | CheckpointCompleteLinesOnly | boolean | False | Yes | When enabled, an incremental read stops after the last complete line. An unfinished trailing line is kept for the next successful read. This is intended for tail-style polling of growing text files. | — |
| `CheckpointFile` | CheckpointFile | string | "" | Yes | Optional checkpoint file for incremental input. The first successful query reads all records; later successful queries using the same source and checkpoint read only appended records. A filename without a directory is stored in the system temporary directory. Failed or cancelled queries never advance the checkpoint. | — |
| `CheckpointStartAtEnd` | CheckpointStartAtEnd | boolean | False | Yes | When enabled and no checkpoint exists yet, begin after the current input instead of reading its existing records. Later reads return appended records. This is useful for tail-style monitoring. | — |

| `IgnoreConvertExceptions` | IgnoreConvertExceptions | boolean | False | Yes | Ignore conversion exceptions and return null. Otherwise, string fields will contain the error message for troubleshooting. | — |
