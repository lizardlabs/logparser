# Read-only Windows Registry values from local or remote hives and keys: -i=REG

## Description

Read-only Windows Registry values from local or remote hives and keys. Command line switch to use this input format is -i=REG.

**Category:** Windows system
**Aliases:** `Registry`, `WindowsRegistry`

This read-only provider returns one row per Windows Registry value. It follows the practical REG field and option names from Microsoft Log Parser 2.2. Start with a narrow key and `Recurse=0`; the compatibility default `Recurse=-1` walks descendants.

## Data Provider

Use `HKCU\Environment`, `\HKLM\Software`, or another key under `HKCR`, `HKCU`, `HKLM`, `HKCC`, or `HKU`. Full hive names also work. Separate several keys with commas. `\\computer\HKLM\Software` reads a remote machine with your Windows credentials and permissions. A lone `\` requests all five roots and may be very expensive. URLs and file globs do not apply to REG.

```sql
CREATE VIRTUAL TABLE registry_values USING ParsingModule('HKCU\Environment', '-i:REG -Recurse:0');
SELECT Path, ValueName, ValueType, Value FROM registry_values;
```

## Output Fields

| Field | Type | Description |
| --- | --- | --- |
| `ComputerName` | string | Computer hosting the Registry key. |
| `Path` | string | Full path of the key containing the value. |
| `KeyName` | string | Name of that key. |
| `ValueName` | string | Name of the value; empty for the default value. |
| `ValueType` | string | Registry type such as REG_SZ, REG_DWORD, or REG_BINARY. |
| `Value` | string | Text representation of the value, controlled by MultiSZSep and BinaryFormat where applicable. |
| `LastWriteTime` | timestamp | Last key modification time in UTC. |
